Side-channel defenses

Weight encryption (AES-128-CTR) counts measured, cycles modelled

Total time with decryption divided by time without, CPI 1.3 for the RV32I options. Instruction counts per block are measured on the AES track's RV32I simulator; engines and the CTR overhead are assumptions. Encryption hides the weights but does not stop bit flips: a flipped ciphertext bit flips the same weight bit.

Row checkers in hardware Yosys

2-input gate cells and logic depth (gate levels) for an 8-weight row. One PE multiply-accumulate sets the clock. All three checkers fit in one cycle, so each adds 1 cycle per tile (40 per inference).
